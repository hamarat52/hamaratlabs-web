## 1) hamaratlabs imzasını kaldır
`src/AppIcon.jsx`'te şu satırları (yaklaşık 285-289, "hamaratlabs imzası" yorumunun
altındaki 4 element: glow ellipse, Ink rect, lime rect, beyaz highlight rect) KALDIR.
7 ikonun hepsinden kaldırılacak (zaten hepsi aynı kod yolundan geçiyor, tek yerden
kaldırman yeterli).

## 2) Gerçek Apple squircle
Apple'ın iOS/macOS ikon köşeleri basit bir `border-radius` DEĞİL — "sürekli eğrilik"
(continuous curvature / squircle) matematiği kullanıyor. Bunu ARAŞTIR (web_search/
web_extract ile):
- Figma'nın "corner smoothing" özelliğinin arkasındaki matematik (açık kaynak
  `figma-squircle` npm paketi var — formülünü incele, kopyalamak yerine SVG path
  üretme mantığını anla ve kendi SVG'ine uygula).
- Apple'ın kendi "squircle" / superellipse yaklaşımı (n≈5 superellipse'e yakın ama
  tam o değil — gerçek formülü bul).
Mevcut elle çizilmiş `SQUIRCLE` path sabitini, GERÇEK matematiksel formülden üretilen
bir path ile DEĞİŞTİR (100x100 viewBox'a göre, kenar yarıçapı ~20-22 arası dene,
hangisi Apple ikonlarına en yakın görünüyorsa). İstersen path'i JS'de parametrik
üreten bir fonksiyon yaz (sabit path yerine), böylece boyut değişirse de doğru kalır.
