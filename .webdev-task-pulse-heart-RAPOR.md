## Dürüstlük notu

GitHub'ın herkese açık API'si bir ziyaretçi adına GERÇEK bir yıldız (star) atmaya
İZİN VERMEZ. Yıldızlama (`PUT /user/starred/{owner}/{repo}`) yalnızca kullanıcının
kendi GitHub hesabının token'ıyla yapılabilir; sitemiz ziyaretçinin hesabına erişemez
(erişmeye çalışması da OAuth girişi ve token saklama gerektirir, bu kapsamda yok).

Bu yüzden kalp:
1. Repo'nun GERÇEK, CANLI yıldız sayısını gösterir
   (`GET https://api.github.com/repos/{owner}/{repo}` → `stargazers_count`, auth yok).
2. Tıklanınca nabız animasyonu oynar ve GitHub repo sayfasını yeni sekmede açar;
   kullanıcı yıldızı orada, kendi hesabıyla atar.
3. Tarayıcıda artan SAHTE bir sayaç YOKTUR. Gösterilen sayı her zaman GitHub'ın
   verdiği değerdir; tıklamak sayıyı değiştirmez.

## API

```jsx
<PulseHeart repoOwner="hamarat52" repoName="sesver" />
<PulseHeart />  // repo yok → soluk, tıklanamaz, "Henüz GitHub'da değil"
```

Opsiyonel prop'lar: `size` (22), `color` (#ff3b5c), `disabledLabel`, `className`.

Durumlar (`data-state`):
- `loading`: iskelet gösterilir.
- `ready`: gerçek sayı gösterilir.
- `nocount`: API hatası, 404 ya da rate limit durumunda sayı sessizce gizlenir; kalp çalışmaya devam eder.
- `disabled`: repo verilmemiştir.

Önbellek (TTL 5 dk):
- Modül düzeyindeki `Map` ve `sessionStorage` birlikte kullanılır.
- Aynı repo için eş zamanlı istekler tek bir fetch'i paylaşır.
- Hatalar da 5 dk bellekte tutulur; rate limit dolmuşken API tekrar tekrar zorlanmaz.

Erişilebilirlik:
- Kalp gerçek bir `<button>`.
- `aria-label` sayıyı içerir.
- Devre dışı durumda `aria-disabled="true"` ve `role="tooltip"` kullanılır.
- `prefers-reduced-motion` etkinse animasyon atlanır, yönlendirme yine yapılır.

`window.open` tıklama jestinin içinde senkron çağrılır; böylece açılır pencere engelleyicisine takılmaz.
