Altı adım

  1. Hesap açın

    API Market’e kaydolun ve giriş yapın. Uygulamalarınız ve anahtarlarınız bu hesabın altında durur.

  2. Anahtar çifti üretin

    2048 bit RSA çifti. Açık anahtarı yüklersiniz; özel anahtar sizde kalır ve her isteği imzalar.

    # 2048 bit RSA
openssl genrsa -out private.pem 2048
openssl rsa -in private.pem -pubout -out public.crt

  3. Uygulama ekleyin

    Uygulamalar → Uygulama ekle. Selected Scope alanında ürün kategorisini seçin, yönlendirme adresinizi (Redirection URI) yazın ve açık anahtarı yapıştırın.

  4. Access token alın

    Seçtiğiniz API’nin Postman şablonunu test kimlik sunucusuyla kullanın. Kur ve şube gibi bilgi servisleri client credentials ile çalışır; hesap verisi müşterinin onayını ister (authorization code). Token bir saat geçerlidir.

  5. İsteği imzalayın

    Signature başlığı, access token ile sorgu dizesinin (GET) ya da gövdenin (POST) RSA-SHA256 imzasını base64 olarak taşır. Kuveyt Türk İmza Aracı aynı işi masaüstünde yapar.

    import { createSign } from "node:crypto";
const signer = createSign("RSA-SHA256");
signer.update(accessToken + queryString);
const signature = signer.sign(privateKey, "base64");

    İmza kuralı portal dokümanından; yayından önce canlı dokümanla yeniden doğrulanacak.

  6. İlk çağrıyı yapın

    GET /v1/fx/rates döviz kurlarını döndürür. Her yanıt aynı zarfla gelir: veri value içinde, sonuç success alanında, mesajlar results dizisinde.

Gönderiliyor…

curl "https://prep-gateway.kuveytturk.com.tr/v1/fx/rates" \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Signature: $SIGNATURE"
const BASE_URL = "https://prep-gateway.kuveytturk.com.tr";
const res = await fetch(`${BASE_URL}/v1/fx/rates`, {
  headers: {
    Authorization: `Bearer ${accessToken}`,
    Signature: signature,
  },
});
const { value, success, results } = await res.json();
import requests

BASE_URL = "https://prep-gateway.kuveytturk.com.tr"
r = requests.get(f"{BASE_URL}/v1/fx/rates",
    headers={"Authorization": f"Bearer {access_token}",
             "Signature": signature})
body = r.json()  # value, success, results

Konsol ağ isteği yapmaz; yanıt örnektir. value içindeki alanlar canlı Swagger’dan gelir.
