Uç noktalar

Son güncelleme: 16 Kasım 2026. API sürümü v1 (örnek).

Makine tarafından okunur sürüm AI paketinde: openapi/kuveytturk-ornek.openapi.yaml (yalnız bu yollar; şemalar örnek).
