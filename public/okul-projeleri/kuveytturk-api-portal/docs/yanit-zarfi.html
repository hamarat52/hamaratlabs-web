Yanıt zarfı

Her yanıt aynı zarfla gelir: veri value içinde, sonuç success alanında, mesajlar results dizisinde.

Son güncelleme: 16 Kasım 2026. API sürümü v1 (örnek).

Alanlar#

AlanTürAçıklama
valuenesne ya da diziUç noktaya göre değişen veri; şeması Swagger'da (ör. DataRates).
successbooleanİşlem başarılı mı.
resultsdiziMesajlar (uyarı, hata). İç alanları Swagger'da.

Örnekler#

Başarılı (örnek) 
{
  "value": [ /* DataRatesObject */ ],
  "success": true,
  "results": []
}
Başarısız (örnek) 
{
  "value": null,
  "success": false,
  "results": [ /* mesaj nesneleri: alanlar Swagger'da */ ]
}

Yanıtı okuma#

const { value, success, results } = await res.json();
if (!success) {
  // results içindeki mesajları kişisel veri olmadan log'a yazın
  throw new Error("Kuveyt Türk isteği başarısız");
}
body = r.json()
if not body["success"]:
    # results içindeki mesajları kişisel veri olmadan log'a yazın
    raise RuntimeError("Kuveyt Türk isteği başarısız")

HTTP durum kodu ile success alanının birlikte nasıl değerlendirileceği doğrulanacak. Hata durumları: Hata kodları
