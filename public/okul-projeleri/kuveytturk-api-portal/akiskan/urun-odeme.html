Güvenlik, kurulumun parçası

OAuth 2.0

Her çağrı, API Market’te oluşturduğunuz uygulamaya verilen token’la yapılır.

İmzalı istek

Her istek, 2048 bit RSA anahtarınızla atılan RSA-SHA256 imzası taşır. Özel anahtar sizde kalır.

Ayrı test ortamı

Test için ayrı kimlik ve ağ geçidi adresleri; gerçek para hareket etmez.

Kısa ömürlü token

Access token bir saat geçerlidir.
