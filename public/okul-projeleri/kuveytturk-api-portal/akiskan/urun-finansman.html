Finansman kaydına üç çağrı.

Müşterinin izniyle finansman projelerini, ayrıntısını ve taksit planını okuyun. Hepsi GET, yanıt zarfı aynı.

  • GET/v1/loansFinansman projelerini listele; her kayıt bir projectNumber taşır
  • GET/v1/loans/{projectNumber}/infoProje ayrıntısı
  • GET/v1/loans/{projectNumber}/installmentsTaksit planı

Sepette finansman akışı: E-commerce Pre-Approved Monthly Payments, E-commerce Lendings ve E-commerce Get Lending Information portalın Financing sayfasında adıyla listelenir. Yolları Swagger’da yer almadığı için bu taslakta gösterilmez.

Finansman dokümanları →

GET /v1/loans/{projectNumber}/installments

# BASE_URL=https://prep-gateway.kuveytturk.com.tr
curl "$BASE_URL/v1/loans/$PROJECT_NUMBER/installments" \
  -H "Authorization: Bearer ***" \
  -H "Signature: $SIGNATURE"
const res = await fetch(
  `${BASE_URL}/v1/loans/${projectNumber}/installments`,
  { headers: { Authorization: `Bearer ${token}`, Signature: signature } }
);
const { value, success, results } = await res.json();

200 Örnek yanıt · DataGetLoansInstallmentsObject

{
  "value": /* DataGetLoansInstallmentsObject */,
  "success": true,
  "results": []
}

Yol ve model adları API Market Swagger’ından. value içindeki alanlar taslakta uydurulmadı.

Güvenlik, kurulumun parçası

OAuth 2.0

Müşteri verisine yalnız müşterinin kendi girişi ve izniyle (authorization code) erişilir.

Onay müşteride

Özet ve sözleşme KT Mobil’de, müşterinin kendi girişiyle onaylanır.

İmzalı istek

Her istek, 2048 bit RSA anahtarınızla atılan RSA-SHA256 imzası taşır.

Ayrı test ortamı

Ayrı kimlik ve ağ geçidi adresleri; gerçek müşteri yerine test müşterileri.

Kontrollü canlıya geçiş

Canlı adreslere Go Live talebiniz onaylandıktan sonra geçersiniz.
