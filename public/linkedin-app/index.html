Hamarat Labs: Publisher

Last updated: 6 November 2026 · Published by: hamaratlabs (Yusuf Hamarat) · Contact: yusuf.hamarat@ozu.edu.tr

Hamarat Labs: Publisher is a self-hosted publishing tool run by hamaratlabs. It publishes posts that the owner has created to the owner's own LinkedIn member profile and to the Hamarat Labs LinkedIn Page he administers.

What it is (and is not)

  • A private tool used only by its owner, Yusuf Hamarat (hamaratlabs), for his own LinkedIn profile and the Hamarat Labs Page.
  • It is not a public service: there is no user sign-up and no user registration.
  • It does not read other members' data and does not post to any third party's account or Page.

How it works

  1. The account owner signs in on LinkedIn's official sign-in screen and grants permission.
  2. The tool uses only the permissions that were granted, to create the owner's posts on LinkedIn.

Permissions (scopes) requested

  • openid, profile, email: member ID, name, profile photo and email address, used only to show which LinkedIn account is connected.
  • w_member_social: to create posts on the owner's own LinkedIn profile.
  • w_organization_social: to create posts on the Hamarat Labs LinkedIn Page, only if LinkedIn grants this permission to the app.
