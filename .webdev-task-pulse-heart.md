# Görev: "Beğen" kalbi (PulseHeart) — GERÇEK GitHub yıldızına bağlı

## Bağlam
ReactBits'in "pulse-heart" bileşeni (https://reactbits.dev/micro/pulse-heart) —
basınca nabız gibi atan/büyüyen bir kalp animasyonu. Repoda yok, sıfırdan yaz.

Kullanıcının talebi: beğenme özelliği, mümkünse GitHub'a bağlı olsun ("github
eklentisiyle... oluyor mu bilmiyorum").

## DÜRÜSTLÜK NOTU (önemli, kullanıcıya böyle açıklanacak)
GitHub'ın herkese açık API'si bir ziyaretçi adına GERÇEK bir "star" (yıldız) atmaya
İZİN VERMEZ — yıldızlamak her zaman kullanıcının kendi GitHub hesabıyla, GitHub'ın
kendi sayfasında yapılması gereken bir işlemdir. Bu yüzden EN DÜRÜST ve GERÇEK
yaklaşım:
1. Repo'nun GERÇEK, CANLI yıldız sayısını göster (GitHub'ın public API'si, auth
   GEREKMİYOR: `GET https://api.github.com/repos/{owner}/{repo}` →
   `stargazers_count`. Test edildi, çalışıyor, rate limit saatte 60 istek/IP —
   bu trafik için yeterli).
2. Kalbe basınca: nabız animasyonu oynar VE kullanıcı GitHub repo sayfasına
   (`https://github.com/{owner}/{repo}`) yeni sekmede yönlendirilir, orada
   GERÇEKTEN yıldızlayabilir.
3. SAHTE bir "beğeni sayacı" (yalnız tarayıcıda artan, GitHub'a hiç gitmeyen bir
   sayı) YAPMA — bu kullanıcıyı yanıltır, gerçek değer taşımaz.

## İstenen
1. Yeni bileşen: `src/components/rb/PulseHeart/PulseHeart.jsx` + `.css`.
2. Prop'lar: `repoOwner`, `repoName` (örn. "hamarat52", "sesver").
3. Mount olunca GitHub API'den gerçek yıldız sayısını çek, göster (yüklenirken
   iskelet/placeholder, hata olursa sessizce sayıyı gizle — kullanıcıya hata
   göstermeye gerek yok).
4. Tıklanınca: nabız/büyüme animasyonu (ReactBits'in pulse-heart hissine yakın) +
   `window.open('https://github.com/{owner}/{repo}', '_blank', 'noopener,noreferrer')`.
5. GitHub reposu OLMAYAN ürünler için (Pomodoro Restoran, Duo for X, henüz pushlanmamış
   tiTimer gibi) bileşen `repoOwner`/`repoName` verilmediğinde zarifçe gizlensin veya
   devre dışı görünsün (kalp soluk, tıklanamaz, "Henüz GitHub'da değil" tooltip'i).
6. Yıldız sayısını makul bir sürede (örn. 5 dakika) önbelleğe al (aynı sayfada birden
   fazla kalp varsa her biri ayrı ayrı API çağrısı yapıp rate limit'i hızlı tüketmesin).
