## Veri sözleşmesi (data.js'e dokunulmadı)

Zorunlu alanlar (FEATURED/APPS ile aynı): `name`, `lead`, `points`, `platform`, `stage`.

- Konsept çizimdeki satırlar `points` alanından (ilk 4 madde), "Planlanan yetenekler" listesi `points` alanının tamamından üretiliyor.
- Çizim çerçevesi `platform` alanından seçiliyor: Android/iOS/mobil → telefon, diğer durumlar → tarayıcı penceresi.
- `[` ile başlayan yer tutucu değerler (data.js'teki `[...]` kalıbı) gizleniyor.

İsteğe bağlı alanlar; ileride dev aşamasındaki başka ürünler bunları ekleyebilir:
- `devStep`: şu anki adım (1'den başlar). Varsayılan 3, aralık dışı değerler sınırlanıyor.
- `devSteps`: adım adları. Varsayılan: Fikir, Tasarım, Yapım, İç deneme, Açık beta, Yayın.
- `devNote`: "Şu an …" cümlesi; yoksa gösterilmiyor.

Mevcut parçalar yeniden kullanıldı: `AppIcon`, `Link` (nav), `Comments` (`term={app.name}`), `LINKS.contact` / `LINKS.instagram`. Geri linki `/uretiyorum` adresine gidiyor; bu rota App.jsx'te zaten var.

## Doğrulama (gerçek çıktılar)

- Render: Geçici bir harness (`dev-preview.html` + `src/dev-preview.jsx`) kuruldu. Bu harness WingWire'ı `FEATURED` dizisinden import edip `<DevStagePage app={...} />` olarak çiziyordu. Vite dev sunucusunda (port 5247) render başarılı oldu: `.devpage` 1 adet, Geist fontu yüklü. Ekran görüntüleri bu harness ile alındı; harness sonra silindi.
- 375px: `scrollWidth` 375 (yatay taşma yok). `.devpage` içinde sağ kenarı aşan eleman sayısı 0. "Henüz indirilemez" alanı min 48px. Dar ekranda adım şeridi yalnızca noktalara iniyor; adın tamamı yalnızca şu anki adımda gösteriliyor. Yeteneklerdeki "taslak" etiketi alt satıra geçiyor.
- `npm run build`: exit 0 (vite v6.4.4, 113 modül, 803ms).
  NOT: Bileşen henüz hiçbir yerden import edilmediği için production bundle'a girmiyor. Derlenebilirliği Vite dev sunucusundaki render ile doğrulandı. Ayrı bir kütüphane derlemesi de denendi, ama scratch'teki config `vite` paketini çözemediği için çalışmadı. Bu benim doğrulama aracımın hatası; bileşenle ilgisi yok. Entegrasyon turunda App.jsx'e import edildiğinde `npm run build` bileşeni de kapsayacak.
- `npx eslint src/DevStagePage.jsx`: exit 0, temiz.
  `npm run lint` toplamda exit 1 (11 hata / 4 uyarı). Bunların hepsi bu görevden önce var olan dosyalarda: `components/rb/*`, `nav.jsx`, `vite.config.js`. Hiçbiri DevStagePage ile ilgili değil (grep sonucu 0 eşleşme).
- Dokunulmayan dosyalar: `git diff --stat -- src/App.jsx src/AppPage.jsx src/data.js` boş döndü.
  `git status`: yalnızca yeni dosyalar var. `package-lock.json` değişikliği görevden önce de vardı, bu çalışmayla ilgili değil.

## Entegrasyon turu için not (yapılmadı)

App.jsx'te `appMatch` bulunduğunda `app.stage === 'dev'` ise `<DevStagePage app={app} />`, aksi hâlde `<AppPage …/>` render edilebilir. WingWire'ın kendi özel sayfası ayrı adreste kalacaksa, o rota bu kontrolden önce eşleşmeli.
